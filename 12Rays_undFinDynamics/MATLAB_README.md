## ترتيب حسب الأهمية والوظيفة

### ⭐ الدوال الأساسية (Core Functions)
هذه الدوال تمثل النواة الحسابية للمشروع:

| الملف | الوظيفة | المعادلة | المدخلات | المخرجات |
|-------|---------|----------|----------|----------|
| `hydrodynamicforces_Func.m` | القوى الهيدروديناميكية على لوحة غشاء واحدة | Eq. 13 | D, hmax, q[1×2], dq[1×2] | F[3×1] = [Sway; Heave; Surge] |
| `hydrodynamictorques_Func.m` | عزوم المفاصل من الأحمال المائية | Eq. 15 | D, hmax, q[1×3], dq[1×3] | T[3×1] = [T1; T2; T3] |
| `DeltaFunc.m` | تشوه الغشاء المرن | - | D, x, q[1×2] | Delta (scalar) |

## المتغيرات العامة (Globals) — مطلوبة للدوال الأصلية
```matlab
global l v Cn rho hmin alpha Phi A f N X
```
| المتغير | الوصف | الوحدة | القيمة الافتراضية |
|---------|-------|--------|------------------|
| l | الطول المميز | m | 0.08 |
| v | نسبة بواسون | - | 0.5 |
| Cn | معامل السحب العمودي | - | 2.65 |
| rho | كثافة المائع | kg/m³ | 1022 |
| hmin | أدنى ارتفاع للغشاء | m | 0 |
| alpha | نسبة هندسية | - | 1 |
| Phi | الإزاحة الطورية | rad | deg2rad(40) |
| A | سعة التذبذب | rad | deg2rad(30) |
| f | تردد التذبذب | Hz | 2 |
| N | عدد الأشعة | - | 3 |
| X | الإزاحة الزاوية | rad | 0 |
